# 2022年认知与社交技能变量试运行报告

结论：程序已按非AI技能v0.1规则完成2022年候选变量构建。结果仅用于诊断和人工复核，不能在人工验证前称为正式变量。

## 1. 样本和文本

- 回归底表记录：328,548条；
- 职位描述可用于判断：328,225条（99.90%）；
- 文本不可判断：323条（0.10%）。

## 2. 初步识别结果

- `skill_cognitive = 1`：70,532条（21.47%）；
- `skill_social = 1`：167,487条（50.98%）；
- 两类技能同时为1：51,499条（15.67%）；
- 两类技能均为0：141,705条（43.13%）。

以上比例反映词典规则的候选覆盖，不等于人工确认后的真实技能需求比例。

## 3. 当前规则

- 只使用含义完整的严格词和条件短语；
- 单独出现“分析、研究、沟通、团队、表达”等泛词不命中；
- 同一分句中存在“不要求、无需、无须、不必、不限”等否定表达时排除；
- 排除明显的公司介绍、福利、团队氛围和数据来源水印；
- 岗位名称只用于抽样，不直接决定技能变量。

## 4. 人工复核

已生成240条分层复核样本，覆盖认知单独命中、社交单独命中、两类同时命中、条件词命中、未命中的技术岗位和未命中的其他岗位。人工应只看原始招聘文本，分别标注认知和社交技能为1、0或9（无法判断）。
