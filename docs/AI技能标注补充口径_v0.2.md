# AI技能标注补充口径（v0.2）

更新：2026-11-18（B）

## 一、这份文件是什么

《AI技能标注对齐说明_v0.2》第三部分写了标1、标0、标9的基本规则和5个待定标签，但有些常见情形没有写明，两人标注时分歧主要出在这里（第一轮重叠样本12条分歧中11条属于这类情形）。

本文件把**A在205条标注中的实际做法**归纳成补充口径，供复核、裁定和以后补标时使用。归纳方法：按关键词找出每类情形在A表中的全部广告，看A的标注是否一致；一致的直接写成口径，不一致的逐条看原文后说明。

本文件只补充、不修改对齐说明里已有的规则。与对齐说明冲突时，以对齐说明为准。

## 二、总原则

> **看到一种具体的AI方法、模型或工具，并且是对这个岗位本人的要求，才标1。**

只出现“智能”“视觉”“算法”等字眼，或只涉及行业、产品、专业，一律标0。

判断时依次问三个问题：

1. 原文里有没有**具体的**AI方法、模型或工具？（深度学习、目标检测、大模型、OpenCV、ChatGPT等；“智能化”“AI产品”不算）
2. 它是不是**这个岗位要会的**？（不是公司介绍、产品介绍、客户行业）
3. 它是不是**必须或优先**的要求？（“者优先”算；“以下一种或多种”里的可选项不算）

三个都是“是”，标1；任何一个是“否”，标0；原文信息不够、回答不了，标9。

## 三、补充口径

### 3.1 偏向标0的情形

|情形|口径|A表中的依据|
|---|---|---|
|**机器视觉、视觉检测、Halcon、VisionPro**，没有深度学习、目标检测、图像识别等词|**标0**。这类多为工业视觉设备的调试、检测和维保，不是AI技能。同时出现深度学习等词才标1|13条全标0|
|**SLAM、激光雷达、路径规划、导航**|**标0**。属于机器人导航与控制|11条全标0|
|**统计和数据挖掘方法**：聚类、决策树、回归、降维、“数据挖掘”，没有机器学习等词|**标0**。按统计分析技能处理。写明“机器学习”或同时有深度学习等词才标1|17条全标0|
|**AI行业、AI产品经验优先**：如“智能音箱产品经验优先”“机器人行业经验优先”|**标0**。行业经验不是技能|4条中3条标0；唯一标1的一条另有AI工具使用要求|
|**了解AI在某领域的应用**：如“了解人工智能技术在车上的应用”“对RPA、OCR等智能技术有认知”|**标0**。属于泛泛了解|2条均标0|
|**可选项**：“了解以下一种或多种：……强化学习”|**标0**。可以用非AI选项满足|1条标0|
|**“多模态”指多传感器数据或出现在公司介绍里**|**标0**|2条均标0|

### 3.2 偏向标1的情形

|情形|口径|A表中的依据|
|---|---|---|
|**OpenCV作为技能要求**：如“熟练掌握OpenCV”|**标1**，类型traditional。只在公司介绍或产品说明里出现的标0|作为技能要求的标1|
|**知识图谱、推荐算法、OCR识别算法作为技能要求**|**标1**，“者优先”也算|知识图谱5条全标1；推荐算法5条中4条标1；OCR算法岗标1|
|**多模态模型或算法**|**标1**|大模型和AI算法岗4条标1|
|**用AI工具完成专业工作**：如AlphaFold预测蛋白结构、“利用AI工具设计新酶”、用ChatGPT检索加工信息|**标1**，备注写`AI工具使用`。ChatGPT等生成式工具填generative，AlphaFold等填traditional|4条全标1|

### 3.3 不看标题、看内容

|情形|口径|A表中的依据|
|---|---|---|
|**标题含“算法”**|看描述里的方法：运筹算法、泊车算法、导航算法、控制算法标0；深度学习、推荐、图像识别算法标1。描述里没有任何AI词的，按对齐说明的`仅算法岗`标0|23条中13条标1、10条标0，全部按描述判断|

## 四、需要注意的一处

编号38的原文只列了“计算机、算法、图像、人工智能等专业”，没有技能要求，按对齐说明的`仅专业`应标0，A标了1。这是A自己的例外，不作为口径依据；裁定时建议按`仅专业`标0。

## 五、怎么用

1. **裁定分歧**：先按对齐说明判断，对齐说明没写到的按本文件判断，在裁定表的“裁定说明”里写对应条目（如“补充口径3.1机器视觉”）。
2. **复核B表**：B表中与本文件口径不一致的广告（如机器视觉标1或9、AI工具使用标0），建议两人复核，Agent只列出、不改标注。
3. **口径变动**：两人决定改本文件中的某条口径时，在这里修改并写明日期，对已标注的同类广告统一重标。

本文件不含广告原文，可以进Git。
