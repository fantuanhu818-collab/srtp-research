# 工资极端值诊断：2018年平台11的年薪误录（2026-11-19，B）

工资变量由A负责（`confirmed_core_v2.wage_mid`来自`cleaned_v1.月薪代表值`）。本文只做诊断和建议，**没有改动任何数据**，是否修正、怎么修正由A决定。

## 一、问题在哪里

月薪超过10万元的广告，几乎全部集中在两个“年份×平台”：

|年份|平台|广告数|月薪>10万占比|中位月薪|
|---|---|---:|---:|---:|
|2018|平台11|284,237|**26.14%**|16,000|
|2021|平台72|123,303|**3.69%**|12,500|
|其他年份×平台（广告数>2万）|—|—|0—0.32%|4,500—15,000|

平台11在2019年完全正常（>10万占比0%，中位数10,000），所以不是平台本身工资高，而是2018年那一批数据的问题。

2018年平台11的工资呈**双峰**：58%在1千—3万元，约40%在6万—100万元，中间3万—6万元只有2%。高值只出现在**4—9月**（每月14%—63%），1—3月和10—12月为0。最常见的高值区间是120,000—180,000、70,000—100,000、100,000—120,000，与常见的年薪写法一致。

## 二、为什么判断是年薪

1. **同一企业、同一岗位名称对照**：2018年平台11月薪≥6万的广告，与同一企业、同一岗位名称在2018年月薪<3万的广告配对，共39,042对。高值是正常值的**中位数13.2倍**（四分位12—15倍），正好对应12—15个月的年薪；
2. **除以12后分布正常**：高值组除以12后中位数11,250元（四分位7,500—16,250），正常组中位数8,000元（6,500—10,000），量级一致；
3. 职位描述里写“年薪”的比例高值组和正常组都只有0.4%，说明单位来自平台的工资字段，不是广告正文。

2021年平台72的高值组（7,199条，常见区间100,000—150,000、150,000—200,000）是同样的模式。

### 错误是哪一步产生的

- **原始数据里就有，不是清洗产生的**：原始文件`上市公司招聘数据2018.csv`的“最低月薪”“最高月薪”已经是120000、180000等数值（`cleaned_v1`中的`最低月薪_原始`与清洗后数值一致）；
- **来源是数据商的字段转换**：数据商字段说明显示，原始数据库存的是薪资文字（如“4千-6千”）和**年薪**数值（`annual_salary_range_start/end`，样例48000、72000），交付给我们的年度文件再换算成月薪。2018年平台11的4—9月、2021年平台72有一部分记录很可能漏了这一步，年薪直接进了月薪字段；
- **清洗没有发现**：`04_clean_recruitment_data.py`的工资规则只处理非数值、≤0、上下限颠倒和单端缺失，没有检查单位或数量级。原始文件不含薪资文字字段，无法逐条还原，只能按规则修正。

## 三、对结果的影响

试算规则：2018年平台11、2021年平台72中月薪≥60,000的广告视为年薪，除以12（共119,477条）。

|年份|对数工资差（AI−非AI）原值→修正后|平均月薪 原值→修正后|月薪>10万占比 原值→修正后|
|---|---|---|---|
|2018|0.850 → 0.814|22,659 → 10,134|5.60% → 0.05%|
|2021|0.667 → 0.676|13,458 → 12,255|0.62% → 0.14%|
|全样本|0.691 → 0.690|14,991 → 11,586|1.65% → 0.15%|

- **对数工资差和回归影响很小**：误录在AI岗位和非AI岗位中比例接近（2018年分别为9.9%和8.4%），对数差只在2018年下降0.04；
- **对工资水平和均值影响很大**：全样本平均月薪高估约30%，2018年高估一倍多；描述统计中原始月薪、标准差、2018年分年工资都受影响；
- 现有的按年1%/99%缩尾**处理不了**：2018年第99百分位本身就是27万元，缩尾后上限仍为27万。

## 四、建议（供A决定）

1. **在核心变量中修正**：对2018年平台11、2021年平台72，月薪代表值≥60,000时除以12，并加一个标记变量（如`wage_annual_fixed`）。规则统一、可复现，影响约11.9万条；
2. **敏感性**：门槛改为50,000或80,000各做一次；或不修正、直接删掉这两个“年份×平台”的高值记录，作为稳健性检验；
3. **还没查清的**：2019年仍有0.81%的广告月薪>10万，来自样本量较小的平台，需要再看；3万—6万元的灰色区间（平台11约2%）无法区分年薪和高月薪，按规则不改；
4. 修正前，中期报告的描述统计以**对数工资和中位数**为主，均值类数字注明受2018年年薪误录影响。

所有结果为描述性诊断，不含广告原文。
