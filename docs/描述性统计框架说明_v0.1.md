# 描述性统计框架说明 v0.1

更新日期：2026-11-19　负责人：B（李宇白）　复核人：A（胡嘉琪）

程序：`code/stata/20_descriptive_stats.do`（明细表图）、`code/stata/21_paper_tables.do`（论文格式三张表）。输入由`code/python/30_build_descriptive_input.py`生成。状态：已在真实数据上运行，AI变量为终版`ai_skill_dict_v1.0`（11-19重跑）。

## 一、它回答什么问题

中期要求“完成描述性统计”。本程序按分工方案输出：样本量、工资分布、AI岗位占比，以及AI岗位占比在时间、学历、经验、城市、行业、职业上的分布。

**所有结果都是未控制任何因素的原始比较**。表中的`raw_ln_gap`（AI与非AI岗位平均对数工资之差）不是AI技能的工资溢价，只是给后续基准回归做参照：加入控制变量和固定效应后系数变小多少，正好说明原始差距里有多少来自岗位构成不同。

## 二、输入数据接口（需要A交付的DTA）

一行一条招聘广告，`source_record_id`唯一。

|变量|类型|是否必需|说明|
|---|---|---|---|
|`source_record_id`|字符串|必需|唯一，用`isid`检查|
|`year`|整数|必需|招聘发布年份|
|`year_month`|日期（%td/%tc/%tm或"2022-01-01"字符串均可）|必需|招聘发布月份|
|`wage_mid`、`ln_wage`|数值|必需|v2口径|
|`education`|字符串|必需|只能是：不限、高中及以下、大专、本科、硕士、博士，或空|
|`experience`|字符串|必需|只能是：不限/应届、1年以内、1—3年、3—5年、5年以上（“—”为中文破折号），或空|
|`city_id`|字符串|必需|v2初版口径，可空|
|`ai_skill`|0/1/缺失|必需|AI技能线交付|
|`ai_skill_broad`、`ai_genai`、`ai_traditional`|0/1/缺失|可选|有则自动加入各表和图|
|`industry_id`、`occupation_id`|字符串或数值|可选|有则自动输出前30类；`occupation_id`尚未构建，暂时跳过|

学历、经验出现上述以外的取值时程序直接报错（`encode ..., noextend`），防止口径不一致被悄悄忽略。

## 三、怎样运行

Mac（B电脑，Stata MP 16）：

```bash
scripts/run_stata_task.sh code/stata/20_descriptive_stats.do \
  outputs/analysis/descriptive_2022/descriptive_stats.log \
  "<分析数据DTA路径>" "outputs/analysis/descriptive_2022" 2022
```

Windows（A电脑），在Stata命令窗口中运行（现有`run_stata_task.ps1`不能给do文件传参数）：

```stata
cd "D:/SRTP科研"
do code/stata/20_descriptive_stats.do "D:/SRTP/工作数据/stata/<分析数据>.dta" "outputs/analysis/descriptive_2022" 2022
```

第三个参数为年份，写`all`则使用全部年份。日志末尾出现`STATA_TASK=PASS`才算运行成功；日志中还会写出`INPUT_ROWS`、`DESC_SAMPLE_ROWS`、`AI_SHARE`、`RAW_LN_WAGE_GAP`等关键数字，便于复核。

## 四、输出

|文件|内容|
|---|---|
|`t1_sample_flow`|样本构成：全部记录、工资有效、AI无法判断、描述统计样本、AI岗位数，以及学历/经验/城市缺失数|
|`t2_summary_stats`|工资、对数工资和AI变量的N、均值、标准差、最小值、P10、中位数、P90、最大值；分全样本、非AI岗位、AI岗位|
|`t3_by_year`、`t4_by_month`|各年、各月的样本量、AI岗位数和占比、平均与中位工资、AI与非AI平均对数工资及原始差|
|`t5_by_education`、`t6_by_experience`|同上，按学历、经验分组|
|`t7_by_city_top30`|同上，样本量最多的30个城市|
|`t8_by_industry_id_top30`、`t8_by_occupation_id_top30`|变量存在时输出|
|`t9_composition_*`|AI与非AI岗位各自的学历、经验构成（组内占比）|
|`f1_ai_share_by_year`|各年AI岗位占比（严格、宽泛、生成式、传统）|
|`f2_ai_share_by_month`|各月AI岗位占比，虚线标出2022年11月ChatGPT发布|
|`f3_ln_wage_density`|AI与非AI岗位对数工资分布|
|`f4_ln_wage_by_year`|各年AI与非AI岗位平均对数工资|

表格同时保存为`tables`下的CSV（汇总数字，不含广告原文，可以上传GitHub）和`descriptive_tables.xlsx`（每张表一个工作表，便于查看，不上传）。图同时保存可编辑的`.gph`和PNG；Mac版Stata 16批处理不支持导出PNG，会自动改存PDF。

统计口径：`t1`之后只保留工资与`ai_skill`均有效的记录；学历、经验、城市缺失的记录保留在总体统计中，只在按该变量分组时剔除。

### 论文格式表（`21_paper_tables.do`，放进中期报告和论文用这三张）

```bash
scripts/run_stata_task.sh code/stata/21_paper_tables.do outputs/analysis/descriptive_all/paper_tables.log \
  "<descriptive_input_all.dta>" "outputs/analysis/descriptive_all"
```

|表|内容|
|---|---|
|`paper_t1_summary`|主要变量的观测数、均值、标准差、最小值、中位数、最大值（月薪原始值与缩尾值、对数月薪、四个AI变量、学历/经验/一线城市虚拟变量）|
|`paper_t2_balance`|AI与非AI岗位的均值、差值、标准误、t值、p值（不等方差t检验）和标准化差异|
|`paper_t3_by_year`|分年份样本量、AI岗位占比、宽泛版占比、生成式AI占比、AI与非AI岗位对数工资及差值|

输出为`tables/paper_t*.csv`、`paper_tables.xlsx`和`paper_tables.docx`（Word表格，可直接贴进报告）。口径按经济学论文常用做法：

1. **工资缩尾**：按年份在第1和第99百分位缩尾，对数工资由缩尾后工资计算；原始工资同时报告。原始月薪最小1元、最大969万元，2018年5.6%的广告月薪超过10万元，多为年薪写进月薪等录入错误，不缩尾会严重拉高均值和标准差；
2. **标准化差异**（Imbens & Rubin 2015）：大样本下t检验几乎总是显著，比较两组差异大小看标准化差异，绝对值大于0.25视为差异较大；
3. 所有结果为描述性比较，不能解释为AI技能的工资效应。

## 六、还没做 / 待讨论

- 地区只到城市；按省份或东中西部分组需要正式行政区划映射（A的城市变量后续工作）；
- 职业分布要等`occupation_id`；
- 是否需要加权（如按招聘人数）尚未讨论，当前每条广告权重相同；
- 单年份运行时，年度图只有一个点，应主要看月度图。
