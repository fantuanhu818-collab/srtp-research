# occupation_id V4.2规则补充与2022年试运行

## 一、这轮解决什么问题

V4.1在全样本中的职业类型覆盖率为71.42%。未分类记录多，不是因为全部岗位都无法判断，而是原规则为了避免误判，对模糊职位名称采取了较严格的保留Z99策略。

V4.2的目标是：在不修改V4.1现有分类的前提下，只给Z99补充职业类型。新增分类必须留下可检查的证据，不能为了提高覆盖率而强行分类。

## 二、V4.2采用的分层方法

### 1. 高精度岗位名称规则

对含义明确的岗位名称使用规则。例如“IPQC主管”对应质量检验与安全，“医疗信息化销售经理”对应销售。

这类规则同时设置排除词。例如标题出现“销售会计”“销售行政”“无销售客服”时，不能因为有“销售”二字就归入销售类。

### 2. 岗位名称加职位描述

岗位名称指出一个候选职业，职位描述再提供同方向证据。例如标题含“工艺”，描述同时出现“生产工艺、工艺流程”，才接受生产制造与工艺。

### 3. 多项职位描述证据

对“工程师、专员、储备干部”等含义不清楚的名称，不单凭标题分类。只有职位描述中至少出现两项相互独立的强证据，且领先第二候选类别，才接受分类。

### 4. 模糊名称匹配加职位描述

参考招聘岗位名称与职业名称词典的模糊匹配方法，保留相似度80分以上的候选。但模糊匹配只提供辅助证据，必须得到职位描述强证据支持，不能单独决定职业类型。

### 5. 初级分类只作辅助

原数据的“初级分类”最多增加1分，只能确认已有判断，不能单独生成occupation_id。

## 三、证据打分和接受条件

- 高精度岗位名称：8分；
- 一般岗位名称强证据：4分；
- 每项职位描述强证据：2分；
- 每项职位描述辅助证据：1分；
- 80分以上模糊名称与候选类别一致：2分；
- 初级分类与候选类别一致：1分。

候选类别同时满足以下条件才被接受：

1. 第一名总分至少5分；
2. 第一名至少领先第二名2分；
3. 有高精度岗位名称、一般岗位名称、两项独立职位描述强证据，或“模糊名称加一项职位描述强证据”中的一种证据组合。

如果不同类别得分接近，继续保留Z99，交给人工复核或下一轮规则完善。

## 四、2022年试运行结果

- 总记录：328,548条；
- V4.1已分类：239,554条，覆盖率72.91%；
- V4.2候选版从Z99新增分类：12,165条；
- V4.2候选版已分类：251,719条，覆盖率76.62%；
- 仍为Z99：76,829条；
- V4.1中原先已经分类的记录被修改：0条。

覆盖率只提高约3.70个百分点，说明当前规则仍不足以直接达到82%—85%的预期。主要剩余问题是：

1. 很多岗位只有一项证据，达不到可靠分类门槛；
2. 大量长尾岗位名称没有进入现有词典；
3. 同一岗位名称在不同行业中可能对应不同职能，需要更细的上下文短语；
4. 如果只降低分数门槛，覆盖率会提高，但误判也会明显增加。

因此，本轮没有为了追求覆盖率而降低门槛。

## 五、人工复核样本怎么组成

400条复核样本采用分层抽样：

- 高精度名称加职位描述：60条；
- 仅高精度名称：20条；
- 一般名称加职位描述：80条；
- 多项职位描述证据：120条；
- 模糊名称加职位描述：80条；
- 仍未接受、保留Z99的边界记录：40条。

人工复核时，只判断候选职业代码和职业名称是否符合该岗位的主要工作内容：

- 正确：候选职业类型正确；
- 错误：候选职业类型错误，尽量填写正确的37类代码；
- 无法判断：岗位名称和描述仍不足以判断，可以继续保留Z99。

## 六、人工复核后的规则修改

完成400条复核后，按错误原因分别处理：

1. 岗位名称方向错误：增加排除词或调整高精度名称规则；
2. 职位描述证据错误：删除过于宽泛的短语，补充更具体的上下文；
3. 两个职业类别冲突：增加职能优先规则或提高分差要求；
4. 可以判断但仍为Z99：补充同义岗位名称、职业词典名称或描述短语；
5. 确实无法判断：继续保留Z99，不强行分类。

只有当400条新样本的可判定记录准确率达到90%，并且V4.1既有人工确认结果不退化时，才进入2018—2025年全量V4.2构建。

## 七、数据集状态

- V4.1仍是当前正式职业类型候选数据；
- V4.2目前是2022年试运行候选版，不用于回归；
- V4.2全量版尚未生成；
- 后续全量运行也会写入新目录，不覆盖V4.1。
