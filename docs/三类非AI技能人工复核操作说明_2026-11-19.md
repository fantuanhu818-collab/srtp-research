# 三类非AI技能人工复核操作说明

## 1. 本轮复核的目的

本轮不是直接修改变量，而是用同一批招聘广告检查软件技能、认知技能和社交技能三套识别规则。人工判断将用于发现误判、漏判和规则边界问题，为下一轮修改词典与识别规则提供依据。

复核工作簿：`outputs/non_ai_skill_review_20261119/三类非AI技能人工复核表_2022_v0.1.xlsx`

## 2. 样本和分工

- 共240条互不重复的2022年招聘广告。
- 六个抽样层各40条：专业软件技能、办公软件技能、条件词或多技能重叠、认知技能命中、社交技能命中、三类均未命中。
- 每层包含10条双人独立复核、15条仅A复核、15条仅B复核。
- 双人独立复核共60条；A和B各需要复核150条。
- “三类均未命中”层由20条技术岗位和20条其他岗位组成，用来检查漏判。

样本显示顺序已经打散。“人工复核”工作表没有程序判断和抽样层信息，避免人工判断被程序结果影响。

## 3. 填写规则

每名复核员都需要判断三类技能：

- `1`：招聘广告明确要求该类技能；
- `0`：通读岗位名称和职位描述后，没有发现该类要求；
- `9`：文本过短、语义含糊或证据相互矛盾，无法可靠判断。

A填写黄色区域，B填写蓝色区域。双人样本必须先独立完成，不能在填写前讨论。

## 4. 操作顺序

1. 打开工作簿后先阅读“填写说明”。
2. 进入“人工复核”，按“分配给”列填写自己的三项判定；拿不准时选9并在备注中说明原因。
3. 两人完成独立复核前，不要打开“程序结果”。
4. 两人完成后，再对照“程序结果”。双人判断不一致的记录会被标记为需要裁决。
5. 汇总人工结果后，再根据误判和漏判类型修改三套规则并重新试跑。

## 5. 版本说明

本轮使用的是试跑阶段的候选变量，不是最终回归变量。软件技能中包含办公软件。认知技能和社交技能仍需根据本轮复核结果调整。

两套候选特征对“有可识别文本”的旧口径有177条差异：软件脚本允许只有岗位名称，认知/社交脚本要求职位描述可用。统一复核采用并集口径，即岗位名称或职位描述任一可用即可进入抽样；这一差异不改变已有候选变量，只影响复核样本的可选范围。
